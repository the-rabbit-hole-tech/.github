## 🧩 What we build

the rabbit hole tech, llc builds software in the open and for business: three open-source products, each in its own org, and two commercial products. Product news and updates are posted on [therabbithole.com](https://therabbithole.com).

**Open source:**

- [CryptOS-PKI](https://github.com/CryptOS-PKI): an immutable, API-driven PKI operating system. It applies the Talos Linux approach to certificate authorities: no SSH, no shell, mTLS gRPC only, and CA keys sealed in the TPM.
- [Sneakers-PAM](https://github.com/Sneakers-PAM): open-source privileged access management. It covers a credential vault, rotation, approvals, SSH brokering and an appliance.
- [Steward-GRC](https://github.com/Steward-GRC): open-source governance, risk and compliance. It covers policies and procedures, approval workflows, acknowledgements and a hash-chained audit trail.

**Commercial:**

- [Brigade-ITSM](https://github.com/Brigade-ITSM): IT service management. In development.
- [VitalsDA](https://github.com/VitalsDA): healthcare software. Not yet released.

## 🧱 Templates

- [template-os-appliance](https://github.com/the-rabbit-hole-tech/template-os-appliance): a generic appliance template with signed boot, A/B updates that revert on failure, TPM-sealed key custody and a first-boot console. Copy it to start a product's appliance.
- [template-website-docs](https://github.com/the-rabbit-hole-tech/template-website-docs): a starting point for a product website and versioned docs site, with the shared frame, a consent gate, checks and a Cloudflare Pages deploy, and no brand.
- [template-node-mock-server](https://github.com/the-rabbit-hole-tech/template-node-mock-server): a starting point for a product's mock gateway, a standalone Node server that speaks the gateway's wire protocol with resettable invented data.
